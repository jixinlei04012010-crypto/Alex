# Curiosidades — video animado

`curiosidades.mp4` (1920×1080, 30 fps, ~75 s, con música): 8 curiosidades que todo el mundo quiere saber.

Para regenerarlo (necesita Python 3, Pillow, numpy y ffmpeg):

```bash
python3 video/make_video.py
```

Los textos están en la lista `FACTS` de `make_video.py`: cámbialos para hacer otro video.
